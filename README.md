# @turystack/nestjs-cache

Pluggable caching for NestJS with superjson serialization and method-level decorators.

## Installation

```bash
pnpm add @turystack/nestjs-cache
```

### Peer dependencies

The host application provides these:

```bash
pnpm add @nestjs/common @nestjs/core @turystack/nestjs-config ioredis reflect-metadata superjson
```

## Documentation

Options, API reference and examples:

**https://tury.dev/libs/nestjs-cache**

## Development

```bash
pnpm install
pnpm typecheck
pnpm check
pnpm test
pnpm build
```
